# Foundry VTT / Obsidian Bridge check

- [ ] Obsidian Bridge is installed and enabled (Foundry v12–v14).
- [ ] Import `World/`. Folders appear as journal folders, and `[[links]]` become working links between journals.
- [ ] Open a journal made from a note with an infobox and a GM block. Record how `[!infobox]` and `[!gm]` render (a plain blockquote is acceptable for GM-only journals): ______
- [ ] Run **WB: Export player handouts** in Obsidian, then import `Player Handouts/` into a separate journal folder.
- [ ] Search the imported player journals for "GM only" and "gm]". There should be no hits.
- [ ] Set that folder's ownership to **Observer** for players, and check a player account can read it.
- [ ] Edit a note in Obsidian and re-import. Confirm Obsidian Bridge's conflict warning appears if the journal was also edited in Foundry.
